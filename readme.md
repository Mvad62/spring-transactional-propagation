1. Напишите реализацию метода `reduceStock` в классе `InventoryService`.
   - Найти товар по названию, если не нашли - бросить исключение 
   - Если количество товара на складе (в бд) < количество товара в заказе - бросить исключение

2. Настройте транзакции в сервисах таким образом, чтобы при возникновении ошибки в методе `reduceStock` запись в таблице аудита была сохранена.
